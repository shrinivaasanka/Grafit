1. Textbook Knowledge Graphs from OpenAI prompt created for some concepts from mathematics and physics - could be a classroom teaching assistant - 27 May 2026
-------------------------------------------------------------------------------------------------
New python source file AITextbookKnowledgeGraph.py has been added to NeuronRain Grafit repositories that queries OpenAI gpt-5.5 for a user defined concept from textbook and creates a knowledge graph for the concept in DOT format and renders it as image file by prompt query template:
    query="Create a knowledge graph for "+concept+" in DOT format and render it"
Following 3 queries were posed to gpt-5.5 on concepts from mathematics and physics textbooks:
    ai_textbook_knowledgegraph(concept="Michelsen Morley Interferometer")
    ai_textbook_knowledgegraph(concept="Berry-Esseen Central Limit Theorem")
    ai_textbook_knowledgegraph(concept="Proof of Lorentz transformation and Special relativity")
and text format of knowledge graphs are logged to testlogs/AITextbookKnowledgeGraph.log.27May2026 and following are images rendered for above concept queries by ChatGPT prompt that could assist as a teaching slide in classroom:
	testlogs/michelson_morley_knowledge_graph.png
	testlogs/berry_esseen_knowledge_graph.png
	testlogs/lorentz_special_relativity_knowledge_graph.png

2. LangChain Retrieval Augmented Generation(RAG) implementation - OpenAI GPT-5.6 prompts for Answering of Questions from Competitive Examinations and Highschool Board Examinations - an AI EduTech usecase that replaces or supplements manual examination coaching of students - 16 July 2026
------------------------------------------------------------------------------------------
2.1 course_material/TextBookKnowledgeGraphs/AITextbookKnowledgeGraph.py has been updated to
define a langchain RAG function langchain_rag() that takes in a query prompt for default OpenAI model gpt-5.6 (upgraded across the board from gpt-5.5 earlier), creates a deep_agent for OpenAI that invokes the query and prints the retrieved result text.
2.2 Questions from 4 examinations - IIT-JEE, +2 State board of Tamil Nadu curriculum, NEET, UPSC civil services  - are randomly chosen, retrieved from backend textbook references and answer is generated by LangChain RAG. This usecase demonstrates AI coaching as a replacement or teaching aid for manual coaching industry. 
2.3 Documentation for OpenAI Python LangChain RAG by deepagents at https://docs.langchain.com/oss/python/deepagents/rag is followed in above function implementation for installation of langchain dependencies (deepagents, "langchain[openai]", langchain-text-splitters, requests, numpy).
2.4 In addition this example requires LangSmith API Key obtained from https://apac.smith.langchain.com for environment variables LANGSMITH_TRACING="true",LANGSMITH_API_KEY and setting of an additional variable LANGSMITH_DISABLE_RUN_COMPRESSION=true as documented in https://github.com/langchain-ai/langsmith-sdk/issues/1769 for compression runtime errors.
2.5 Four set of examination questions earlier answered by RAG are at testlogs/AITextbookKnowledgeGraph.log.16July2026 sourced from textbooks.
